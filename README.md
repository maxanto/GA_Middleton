# GA_Middleton

This repository contains project materials for work related to the Middleton Class A noise model and genetic algorithms.

## Repository Contents

- [`VHDL/`](VHDL/README.md) contains the hardware implementation and its setup notes.
- [`docs/`](docs/README.md) is reserved for project documentation.
- [`notebooks/`](notebooks/README.md) is reserved for notebooks and related materials.

The contents of the documentation and notebooks folders may change as the project develops. Refer to the README in each folder for any available information.
