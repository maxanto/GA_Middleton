# 🧪 Notebooks

This folder contains the Python/Jupyter Notebook implementation used for the simulation, validation, and performance analysis of the genetic algorithm applied to Middleton Class A noise estimation.

## 📄 Contents

| File | Description |
|---|---|
| `Algoritmos_geneticos.ipynb` | Main notebook with the noise model, genetic algorithm implementation, convergence analysis, and result validation. |

## 🚀 How to Run

1. Clone the repository and navigate to the project root:

```bash
git clone <repository-url>
cd <repository-name>
```

2. Create and activate a virtual environment (recommended):

```bash
python -m venv .venv
source .venv/bin/activate      # Linux / macOS
# .venv\Scripts\activate       # Windows
```

3. Install the required dependencies:

```bash
pip install jupyter numpy matplotlib scipy
```

> If the repository includes a `requirements.txt`, use `pip install -r requirements.txt` instead.

4. Start Jupyter Notebook or JupyterLab:

```bash
jupyter notebook
# or
jupyter lab
```

5. Open `Algoritmos_geneticos.ipynb` and run the cells sequentially.

## 📊 Notebook Overview

The main notebook covers:

- Middleton Class A noise modeling
- Genetic algorithm implementation
- Convergence evaluation
- Validation of results
- Performance analysis

## 📝 Notes

- Run the notebook from this folder or from the repository root, depending on how the file paths are defined inside the notebook.
- Generated figures and intermediate results may be saved locally when running the notebook.
